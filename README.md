## 二、简历核心项目详述

### ① [分布式光伏指数保险定价](https://github.com/b-bzy/distributed-pv-index-insurance)

`上海立信会计金融学院 · 国家级大学生创新创业训练计划项目负责人 · 2022.10 – 2024.05`

作为总负责人牵头 20+ 人跨学科团队完成为期两年的研究。基于 NASA POWER 卫星辐照数据（1984–2022 共 468 个月 GHI 数据），用 ARIMA(1,0,1)(2,0,1,12) 对辐照建模预测，以累积能量产出（AEP）为指数触发器设计分布式光伏指数保险产品，按分位数逐月厘定费率（触发水平 P75 时年费率 8.04%，P90 时 2.74%）。仓库归档论文、参赛作品与获奖证书共 5 份成果。

累计获省级以上奖项 10 余项，包括**美国大学生数学建模竞赛（ICM）国际一等奖**（全球前 8%）等。

`指数保险 / 参数保险` `ARIMA 时序建模` `NASA 辐照数据` `费率厘定` `极值理论` `结构方程模型` `绿色金融`

### ② [期货合规 RAG 问答助手](https://github.com/b-bzy/futures-compliance-rag)

`东海期货（上海总部）· AI 产品经理 · 2024.10 – 2025.03`

针对法规更新频繁、合规文件涉密不可出内网的痛点，设计基于**本地化 RAG 架构**的合规 AI 助手。打通 PDF 文件 OCR 识别 → 语义切分入库 → 混合召回 → 重排序的完整链路，提供对话式合规条款即时查询并给出条款出处。

公开仓库根目录是在公开语料上独立完成的可复现实现：覆盖 10 家境内外交易所的 190 份业务规则与合约条款，通过三路混合召回、自研 score-aware RRF 与交叉编码器重排，实现 Recall@1 0.807。公司项目的脱敏复盘单独收录在 `docs/product_case.md`，不包含公司源码或内部材料。

`RAG` `本地化部署` `金融合规` `OCR` `混合检索` `Rerank` `检索评测`

### ③ [大盘市场情绪 Agent](https://github.com/b-bzy/research-sentiment-agent)

`东海期货（上海总部）· AI 产品经理 · 2024.10 – 2025.03`

基于交易员对大盘情绪指标的需求，搭建研报情绪化打分 Agent。实现批量抓取多家期货公司研报，提取多空观点关键词、设定统计区间、建立评测指标与打分模型，把定性的多空表述转成可横向纵向比较的量化指标，并定期主动推送。

`AI Agent` `金融科技` `研报解析` `情绪量化` `数据采集` `指标设计`

### ④ [跨境电商智能客服系统](https://github.com/b-bzy/cross-border-ecommerce-customer-service-demo)

`NTU × Shopee 校企 Capstone · 项目组长 · 2026.01 – 2026.04`

带领算法与工程组员完成面向 Shopee 跨境电商场景的智能客服对话系统原型设计与实现。围绕多语言服务、意图分流、任务型问答、闲聊解耦、人工接管与服务质检，设计可配置、可评估的人机协同客服方案，并通过 A/B 测试持续优化响应质量。

当前公开仓库为经脱敏处理的作品集骨架：后续仅补充已审核的方案、独立重建的 Demo 和合成示例；不包含生产系统、真实客户会话、订单数据或内部知识库。

`跨境电商` `智能客服` `AI Agent` `多语言服务` `意图路由` `任务型问答` `人工接管` `服务质检`

### ⑤ [跨境电商 AI 语音销售 Agent](https://github.com/b-bzy/ai-voice-sales-agent)

`KapibalaAI（阿联酋总部）· AI 产品经理 · 2026.01 – 2026.08`

面向金融行业与海外电商的 AI 语音外呼产品，从 0 到 1 建设。负责终端系统信息架构设计与 MVP 验证闭环（取任务 → 拨号 → 对话 → 落库），搭建问卷测评台并招募母语测试团队，参与建立**拟人度 / 稳定性 / 转化率**三维 AI 调优评测体系。针对外采 API 成本高、效果差的问题，参与电销场景**全双工语音模型**自研（与高校联合研究），支持数据标注与后训练方向制定，建立 bad case 收集机制并推动自研模型落地。

`AI 语音` `全双工模型` `信息架构` `MVP 验证` `LLM 评测` `后训练` `出海产品`

### ⑥ [电商中台「拍小宝」Agent（飞书工作流）](https://github.com/b-bzy/paixiaobao-feishu-workflow)

`万物新生「爱回收」· AI 产品经理 · 2026.08 – 至今`

从电商中台的一线业务调研出发，设计「拍小宝」Agent，统一承接商品治理问题收集、业务场景分析与流程自动化需求，并搭建飞书业务工作流 POC。产品以**飞书 Bot**承接业务交互，以 **Feishu Base** 管理模板与流程实例，以**妙搭管理员控制台**完成模板草稿、发布与流程查询，并由 Nitro 服务提供业务 API。

优惠券 OA 智能填报是拍小宝下的首个落地功能：针对优惠券申请中材料分散、字段遗漏和跨表核验等问题，完成材料解析、字段预填、结果确认、OA 草稿生成与人工提交的完整流程。生成结果确认后只预填 OA 草稿，正式提交仍由业务员确认；模板实例固定绑定发起时版本，关键操作可回溯。

项目以独立代码库、独立部署与测试数据运行，不复用源系统的部署、凭证或数据源。

`AI Agent` `飞书 Bot / Base` `审批工作流` `人机协同` `业务流程设计` `TypeScript` `Nitro` `Vite`

### ⑦ [会话数据中台 × Agent 标签数据引擎](https://github.com/b-bzy/conversation-data-hub)

`KapibalaAI（阿联酋总部）· AI 产品经理 · 2026.01 – 2026.08`

面向跨境销售业务，把散落在 Telegram / WhatsApp 等多个平台的会话统一聚合成会话资产，并在其上自动加工出模型训练数据。负责中台的产品方案设计与架构框架定义：Connector 抽象、10 张核心表的统一数据模型、入站 / 出站双向消息链路与翻译层。上层设计 **Agent 标签数据引擎**——六维标签体系（意图 / 阶段 / 策略 / 情绪 / 合规 / 结果）、规则预标 → LLM 打标 → 人工抽检的三层漏斗、以成交结果做弱监督的结果回标，让一条对话同时产出 SFT 正样本、DPO 偏好对与蒸馏素材，形成「对话 → 标注 → 训练 → 评测 → 灰度 → 回流」的自进化闭环。

两层之间只通过 **Agent Facade** 一个契约耦合——换平台不影响上层，换模型不影响下层。

`数据中台` `多平台会话聚合` `数据模型设计` `训练数据生产` `数据标注体系` `SFT / DPO / 蒸馏` `弱监督` `多租户`
